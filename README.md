# Jimbo's Ball Battles
Balatro face card set themed around the Youtube series Ham's Ball Battles, with low and high contrast versions of all suits
Comes with a set for human(ish) versions of the characters, and another with the actual weaponballs

(Fanmade, Ham's Ball Battles and it's characters belong to Hamvangolio)

# Install Info

This requires [Lovely](https://github.com/ethangreen-dev/lovely-injector) and [Steamodded](https://github.com/Steamodded/smods), follow their install instructions beforehand.
Afterward, simply take the folder inside the .zip folder and place it in your Mods folder, similar to how you installed Steamodded
